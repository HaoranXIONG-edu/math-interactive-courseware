# 数学教学图示标注规范（可复用标准）

> **适用范围**：初中/高中数学静态高清配图（300 DPI `.png`、波利亚解题讲义图）及交互式 HTML/SVG 动态几何与函数课件。  
> **核心原则**：**真实数学坐标驱动 + 无背景白边光晕直标（减少遮挡）+ 数字角图文联动 + 二维标准公式排版 + 零碰撞渲染**。

---

## 一、字体、正斜体与空格排版规范

1. **字体与正斜体分工**
   - **中文汉字与中文标点**：统一使用 `宋体`（`SimSun` / `Songti SC`），**正体**。
   - **几何顶点、线段字母与代数变量**（如 $A, B, C, D, P, O, x, y, k, n$）：无论在图形旁还是图内图例、公式中，统一使用 `Times New Roman` **斜体**（HTML 中用 `<i class="m">...</i>`）。
   - **数字、计量单位、函数名与几何符号**：统一使用 `Times New Roman` **正体**（不倾斜）：
     - 数字：`0–9`
     - 计量单位：`/m`、`/cm`、`/Pa`、`/A`、`/N`、`/min`、`/mg`、`/Ω`、`°C` 等（中文单位如 `/度` 用宋体正体）
     - 特定缩写/函数名：`Rt`、`sin`、`cos`、`tan`
     - 几何与关系符号：`∠`、`△`、`°`、`∥`、`⊥`、`∽`、`≌`、`=`、`+`、`-`
2. **严禁多余空格**
   - 严禁在中文与字母、数字、运算符、单位之间手动添加空格（应写为 `求BC的长`、`树AB高4m`，不得写为 `求 BC 的长`、`4 m`）。
3. **SVG 特殊字符转义**
   - 严禁在 SVG `<text>` 中直接裸写未转义的 `<` 或 `>`（如 `x<0` 会被 HTML 解析器误判为非法标签 `<0` 导致吞字乱码），必须转义为 `&lt;` / `&gt;` 或统一通过 `window.svgAutoFormatText` 处理。
4. **教学用语规范**
   - 全图与步骤标注严禁出现“秒杀”“秒得”“秒解”“大招”等夸张或口语化词汇，统一使用“快速求出”“直接求得”“化简求解”等严谨教学用语。

## 二、图内数学公式与几何符号规范

1. **分式必须上下叠置（严禁单行斜杠 `/` 拼凑）**
   - 所有函数解析式（如 $y=\frac{2}{x}$、$y=-\frac{4}{x}$）、面积公式（如 $S=\frac{1}{2}|k|$）与设元边长（如 $NF=\frac{4}{3}(4-x)$、$BF=\frac{25-4x}{3}$），必须绘制为**分子居中在上、水平分数线居中、分母居中在下**的标准二维分式。
   - 严禁在图内写 `y = 2/x`、`0.5|k|`、`4/3(4-x)` 或 `(25-4x)/3`。
   - 在 SVG 中可使用 `window.MathFormula.svg` / `window.svgFoLabel`（配合 `.fraction`）渲染。
2. **根式必须带完整水平顶线（Vinculum）**
   - 根号顶线必须完整覆盖被开方数，严禁使用纯文本 `√3` 或 `√(a+b)`（在楷体下 `√` 易退化为中文对勾乱码 `∨`）。
   - 在 HTML 与 SVG `<foreignObject>` 中统一使用 `<span class="sqrt"><span class="num">3</span></span>`。
3. **上下标缩放与偏移**
   - 面积下标与字母数字上下标（如 $S_{\triangle AOB}$、$S_{\text{矩形}OAPB}$、$x^2$、$k_1$）按 `0.75em` 缩放并作精确上下偏移。
4. **相似与全等证明记号红线**
   - **仅全等三角形（`≌`）**允许在括号内标注判定依据：`（SAS）`、`（ASA）`、`（AAS）`、`（SSS）`、`（HL）`。
   - **相似三角形（`∽` 或“相似”）后严禁附加 `（AA）`、`（SAS）`、`（SSS）` 等括号记号**。

## 三、统一视觉令牌与绘制层级（`MATH_THEME`）

### 2. 四层绘制顺序（由底到顶）

为保证图形通透、文字永不被线条遮挡，绘制顺序必须严格遵循：
1. **底层填色层（`fills`）**：柔和半透明的多边形、扇形色块（透明度 `0.15–0.24`）。
2. **几何线框层（`lines`）**：原题实线（`2.6px`）与彩色虚线辅助线（`2.2px`, `dash="7 4"`）。
3. **几何标记层（`marks`）**：数字角圆弧、直角方标、等长短杠、平行箭头、尺规作图弧痕、工程尺寸线。
4. **顶层标注层（`labels`）**：顶点圆点（普通 `r=4.5`、动点 `r=5.5`、圆心 `r=3.8`，带 `1.8px` 白边）、带**白色描边光晕**（`stroke="#ffffff" stroke-width="3.5~4.2" paint-order="stroke"`）的文字与公式、顶部通栏图例条。

## 四、波利亚级（Polya-Grade）核心标注技法

1. **顶部通栏色彩图例条（`window.svgLegendBar`）**
   - 凡出现辅助线、数字角或全等/相似三角形色块时，在画布顶部（`y = 6..36`）渲染浅灰圆角图例条（如 `∠1=∠2=∠3 | ∠4=∠5 | -- BF,EF: 构造筝形 | △FDE∽△BDF`），图例颜色与图内元素 1:1 对应。
   - **严禁**在图形角落堆叠遮挡边线的大块矩形悬浮卡片；**严禁**在图形正下方放置“图2（原题纯享图）”等压住底端顶点的文字标题。
2. **数字角标注与图文联动（`window.svgNumberedAngle` / `geo.angle`）**
   - **严禁画无字空角弧**，也严禁在图内塞入冗长的三字母角名（如 `∠DAH`、`∠EDC`）。
   - 凡涉及导角（外角定理、同角/等角的余角相等）、角平分线或相似/全等对应角，在角弧旁用对应颜色标出纯数字 **`1`、`2`、`3`、`4`、`5`**。
   - **同顶点相邻角阶梯错位**：共顶点的相邻角采用阶梯递增半径（`26px`、`34px`、`42px`、`50px`）错开圆弧；狭窄角（如 `< 28°`）开启 `leader: true` 用细引线引出数字。
   - **左右图文 100% 同步**：左侧推导步骤同步以 `∠1 = ∠2 = ∠3` 书写推导过程（首次引入时注明定义，如 `作∠ABD的平分线BF，则∠1=∠2=∠3`）。
3. **贴边无背景直标与等长/平行标记**
   - **无背景白边光晕直标**：线段数值与代数式优先沿线段外侧法向偏移 `14–16px`（含分式时偏移 `24px`）直接标注，利用白色描边光晕防压线，尽量不使用大块胶囊框遮挡图形。
   - **等长短杠（`tickMarks`）**：第一组等边标单短杠 `/`，第二组等边标双短杠 `//`。
   - **平行箭头（`parallelMarks`）**：平行线段居中标单向或双向小箭头。
4. **求解目标引线标注（`targetCallout` / `svgCalloutTag`）**
   - 在所求目标线段或角旁使用带圆点虚线引线的标注：推导中途显示翠绿色 **`求 BC = ?`**，到达最终步时切换为朱红色高亮结果（如 **`BC = 4√3`**）。
5. **尺规作图与对称标注**
   - 尺规作图保留浅蓝虚线弧痕（`compassArc`，`1.5px`，`dash="4 3"`）。
   - 轴对称构造自动补全紫色虚线连线、垂足直角标及两侧等长单杠。

## 五、坐标系、函数图象与静态原图规范

1. **真实数学坐标与零自由常数**
   - 除驱动动点外，图形中所有顶点（垂足、交点、对称点）必须严格由题干几何条件通过数学公式推导得出，**严禁**硬编码与条件无关的自由常数坐标或口算像素坐标手写多边形。
   - **题干 ↔ 配图字母 1:1 闭合**：图中标注的所有顶点字母集合必须与题干多边形/线段名称 100% 一致。
2. **坐标轴刻度与轴端标签防压线**
   - **刻度避让曲线象限**：反比例函数等曲线穿过特定象限时，坐标轴刻度数字必须标在**无曲线经过的象限侧**（如 $k>0$ 时标在二、四象限侧，$k<0$ 时标在一、三象限侧），并加白色描边光晕。
   - **轴端标签对齐**：$x$ 轴末端标签右对齐（`anchor="right"`），$y$ 轴顶端标签左对齐（`anchor="left"`），杜绝 `y/°C`、`y/度` 等带单位标签压住 $y$ 轴箭头。
3. **动态课件初始态（`step = 0`）零剧透**
   - **原题有配图**：`step = 0` 严格还原原题配图，辅助线与数字角在点击进入对应推导步骤后才动态浮现。
   - **原题无配图（辅助坐标系）**：`step = 0` 只允许渲染空白平面直角坐标系（坐标轴、网格与刻度），严禁提前画出曲线或特征点。
4. **静态原图（300 DPI PNG）补充规范**
   - 白底高分辨率，宽度 $\ge 2400\text{px}$（300+ DPI）；涉及作图或辅助线时，在画布对应方向预留充足留白，避免交点或标注裁边。
   - 嵌入 Word（`.docx`）替换原图时，必须同步清空或校准 `<a:srcRect>` 裁剪框并按真实宽高比更新 `<wp:extent>`，防止边缘被切或拉伸变形。

## 六、质量与防碰撞检查清单（QA Checklist）

交付前逐项核对以下门禁，确保零失误：

- [ ] **无嵌套 `<svg>`**：主 `<svg>` 内部（含 `<foreignObject>`）严禁再嵌套 `<svg>`，所有图元使用原生 `<path>`、`<polygon>`、`<line>`、`<rect>`、`<circle>`。
- [ ] **全包围盒零碰撞**：任意 `<text>` 与 `<text>`、`<ellipse>` 与 `<text>`、`<foreignObject>` 与 `<text>`、`<foreignObject>` 与 `<foreignObject>` 之间零重叠，且不超出画布边界。
- [ ] **无裸斜杠分式**：图内所有分数与含分母代数式均为上下叠置二维分式，无 `a/b` 单行斜杠。
- [ ] **无裸文本根号**：所有根号均有完整水平顶线（`.sqrt`），无裸写 `√`。
- [ ] **无相似度括号记号**：`∽` 或“相似”后未出现 `（AA）`、`（SAS）`、`（SSS）`。
- [ ] **正斜体与空格合规**：顶点/变量为 Times New Roman 斜体，数字/单位/运算符为正体，中文与字母数字间零多余空格。
- [ ] **图文符号 1:1 同步**：图内数字角（`1, 2, 3...`）、顶点字母与左侧/正文推导步骤完全一致。
